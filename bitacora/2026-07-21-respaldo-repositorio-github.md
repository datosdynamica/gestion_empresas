# Respaldo del proyecto en GitHub

Realizado por Leonardo Navarro.

Fecha: 2026-07-21

## Objetivo

Dejar una copia ordenada del proyecto en GitHub, con codigo, documentacion, bitacoras y material de seguimiento que si aporta contexto tecnico y funcional.

## Criterio usado para el respaldo

- Se incluye el codigo fuente del modulo.
- Se incluye la documentacion operativa y funcional.
- Se incluyen bitacoras y seguimientos que ayudan a entender decisiones, pruebas y ajustes.
- Se excluyen archivos sensibles o temporales:
  - llaves
  - tokens
  - datos de conexion
  - runtime local
  - binarios de apoyo
  - videos crudos
  - temporales de prueba

## Aclaracion

El archivo `config/runtime.php` no se sube al repositorio. En su lugar queda `config/runtime.example.php` para mostrar la estructura esperada sin exponer credenciales reales.
